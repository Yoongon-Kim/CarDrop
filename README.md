CarDrop

CarDrop은 여러 대의 차량으로 이동하는 일행이 경로상 가까운 경유지를 추천받고, 투표로 들를 곳을 정하며, 이동 중에도 서로 소식을 나누는 차량용 Social/Communication 앱입니다.

## 빠른 실행

1. Android Studio에서 저장소 루트(`settings.gradle.kts`가 있는 폴더)를 열고 Gradle 동기화를 완료합니다. Android SDK 경로는 Android Studio가 생성하는 `local.properties`의 `sdk.dir`을 사용합니다.
2. Device Manager에서 **Pleos Connect v2.1.0** 에뮬레이터를 시작합니다.
3. 실행 대상에 해당 에뮬레이터를 선택하고 **Run ▶**을 누릅니다. 앱이 위치 권한을 요청하면 허용합니다.
4. 모드 선택 화면이 뜨면 **봇 크루로 시작**을 선택합니다. 크루를 만들고 **이 멤버로 출발하기**를 누릅니다.
5. 홈의 **퀵 드랍 → 휴게소**에서 후보를 골라 투표를 보냅니다. 특정 차량에만 보내려면 **드랍하기 → 누구에게 보낼까요?**에서 먼저 차량을 선택합니다.
6. **DEMO → 투표 바로 마감 (시간 다 됨)**으로 결과를 확인합니다. 결정된 경유지가 왼쪽 CarDrop 지도에 반영되는지 확인합니다.

기본 설정에서는 별도 API 키나 Firebase 설정 파일 없이 에뮬레이터 한 대로 크루·추천·투표 흐름을 체험할 수 있습니다. 이 모드에서는 가상 차량, 샘플 추천, 모의 음성 입력을 사용합니다. 지도 타일과 온라인 경로 계산에는 인터넷 연결이 필요합니다.

## 체험할 기능

### Android 앱에서 체험

| 기능 | 어디서 무엇을 해볼 수 있나요? |
| --- | --- |
| 크루 만들기·참여 | 목적지를 선택하고 크루를 만듭니다. 다른 차량은 6자리 초대 코드로 참여합니다. 초대 코드를 읽어 주거나, 문자 앱이 설치된 기기에서는 초대 내용을 문자 앱으로 전달할 수 있습니다. |
| 주행 홈·일행 위치 | 출발 후 앱 내 지도에서 차량 위치와 경로를 확인합니다. 크루 위치와 남은 시간, 차량별 연료 정보를 확인합니다. 퀵 드랍 편집에서 자주 쓰는 바로가기를 선택해 이 기기에 저장합니다. |
| 받는 차량 선택·편지함 | **드랍하기**에서 크루 전체 또는 개별 차량을 선택합니다. 받은 차량은 편지함에서 제안과 메시지를 확인합니다. |
| 경유지·목적지 제안 | 휴게소·식사 등 주제를 고른 뒤 추천 후보를 선택하거나 장소를 직접 추가합니다. 목적지 변경 제안은 찬성·반대로 응답하며 다른 목적지를 다시 제안할 수 있습니다. 한 대라도 반대하면 기존 목적지를 유지합니다. |
| AI 추천·음성 제안 | “배고파”처럼 말하면 제안 의도를 해석합니다. 일반 추천 화면과 수신 차량의 투표 화면에 후보별 추천 이유가 표시됩니다. 홈의 간단한 팝업에서는 거리와 장소 정보를 확인합니다. |
| 투표·돌림판 | 받은 차량에서 후보를 선택하거나 “1번”, “아무 데나”, “패스”처럼 응답합니다. 고르기 어려울 때는 **고민되면 돌려보기**를 사용합니다. |
| 결정 안내·경로 변경 | 투표 결과를 확인하고 앱 내 지도의 경유지 변경을 볼 수 있습니다. **지금 안내 시작** 또는 **우리 차는 안 들르기**를 선택합니다. |
| 연료 부족 알림 | DEMO에서 연료 부족 상황을 재현합니다. 일행은 **같이 갈래요** 또는 **가던 길 갈래요**로 주유소 동행 여부를 정합니다. |
| 일행에게 한마디 | 자주 쓰는 문구를 추가·수정·삭제하거나 직접 말해 메시지를 보냅니다. 받은 차량에는 소식을 화면으로 표시합니다. |
| 노래 드랍·따라듣기 | **드랍하기 → 노래 드랍**에서 샘플 곡과 받을 차량을 선택해 보냅니다. 받은 차량은 **괜찮아요**로 닫거나 **받아서 바로 듣기**로 현재 곡 표시를 바꿉니다. 시연은 곡 정보와 재생 상태 전환까지 지원하며, Apple Music 계정 연동과 실제 음원 재생은 제공하지 않습니다. |
| 정차 중 AI 퀴즈 | AI기반 초성, 지역 퀴즈 입니다. DEMO에서 기어를 P로 설정하고 게임 초대를 선택해 문제에 답합니다. D로 바꾸면 퀴즈가 멈추고, 다시 P로 바꾸면 이어서 진행합니다. |
| 정차 중 게임 | **게임**에서 상대 차량에 도전장을 보내고 수락 후 게임을 합니다. 참여한 차량 모두 P(정차) 상태여야 활성화 됩니다. 현재는 오목만 구현되어 있고 체스 등 추후 게임을 추가할 예정입니다. |

## 선택 설정

아래 값은 프로젝트 루트의 `local.properties`에서 설정합니다. 설정을 변경한 뒤 앱을 다시 빌드하고 설치합니다.

| 연동할 서비스 | 필요한 설정 |
| --- | --- |
| Pleos 음성 인식·안내 | `cardrop.useRealVoice=true`. 에뮬레이터를 시작할 때 호스트 마이크 입력을 켜고 앱에 마이크 권한을 허용합니다. |
| 크루 위치 공유 | 지원 환경에서 위치 권한을 허용하면 크루 도식에 Pleos FusedLocation SDK 측정값을 우선 사용하고, 유효한 값이 없으면 Android GPS를 사용합니다. 앱 내 길안내는 Android 위치 정보를 사용합니다. |
| 차량 데이터 조회 | `cardrop.useRealVehicle=true`. Pleos Vehicle SDK를 통해 차량이 제공하는 연료 잔량·주행 가능 거리 등을 조회합니다. 기본 모드에서는 DEMO로 연료 부족을 재현합니다. |
| AI 의도 분석·추천 | `cardrop.claudeApiKey` 설정. 미설정 시 샘플 응답을 사용합니다. 현재 빌드는 키를 APK에 포함하므로 공유용 APK는 Claude 비밀 키를 비운 상태로 빌드합니다. |
| 지도·경로·장소 검색 | `cardrop.kakaoRestKey`는 카카오 경로 계산·장소 검색에, `cardrop.kakaoNativeKey`는 카카오 지도 표시에 사용합니다. 키가 없으면 OSRM 경로, MapLibre 지도, 앱에 등록된 장소 목록을 사용합니다. |
| 두 차량 간 실제 투표 | 팀 Firebase 프로젝트의 설정 파일을 `app/google-services.json`에 두고 `cardrop.useRealCrew=true`로 설정합니다. Firebase 설정을 포함한 빌드를 두 기기에 설치하고 시작 화면에서 **실제 크루**와 서로 다른 차량을 선택합니다. 한 차량이 만든 크루에 다른 차량이 6자리 코드로 참여하면 제안·투표와 차량별 위치·연료 상태를 공유합니다. |

### 선택 사항 · 지도에서 차량 이동 시연하기

Python 3.9 이상과 Android SDK의 `platform-tools`를 준비하고 `adb`를 PATH에 추가합니다. 앱 실행 후 저장소 루트에서 다음 명령을 실행하면 영동고속도로 시연 경로를 따라 GPS 좌표가 입력됩니다.

```powershell
python tools/drive_gps.py
```


## APK 파일 위치(제출 전 실제 APK 위치로 수정)

소스에서 직접 빌드한 **테스트용 APK**의 위치는 `app/build/outputs/apk/debug/app-debug.apk`입니다. 저장소 루트에서 아래 명령으로 생성할 수 있습니다.

```powershell
.\gradlew.bat assembleDebug
```

macOS 또는 Linux에서는 `./gradlew assembleDebug`를 사용합니다.
