제출용 APK로 첫 경유지 정하기
Android Studio의 Device Manager에서 Pleos Connect v2.1.0 에뮬레이터를 시작합니다. 위에서 내려받은 APK가 있는 폴더에서 Android SDK Platform-Tools의 adb로 설치합니다.

adb devices
adb install -r CarDrop_CarDrop_release.apk
에뮬레이터에서 CarDrop을 열고 위치 권한을 허용합니다. 봇 크루로 시작을 누르면 에뮬레이터 한 대에서 내 차와 가상 차량 세 대로 체험할 수 있습니다.

크루 화면에서 목적지를 고르고 이 멤버로 출발하기를 누릅니다. 주행 홈 왼쪽에는 CarDrop의 경로 안내 지도가, 오른쪽에는 크루와 드랍 화면이 표시됩니다.

드랍하기 → 누구에게 보낼까요? → 크루 전체 또는 개별 차량 → 휴게소를 선택합니다. 추천 이유와 거리를 비교해 후보 두 곳을 선택하고 이 2곳으로 투표 보내기를 누릅니다.

봇 크루에서 결과를 바로 보려면 **DEMO → 투표 바로 마감 (시간 다 됨)**을 누릅니다. 결정된 휴게소와 앱 내 지도의 경유 경로를 확인합니다. 받는 차 입장도 보려면 DEMO → … 휴게소 투표 받기를 선택해 직접 응답합니다.

이번에는 홈 → 퀵 드랍 → 휴게소를 누릅니다. 팝업에서 한 곳을 확인하고 여기 들르자고 보내기를 누르면 일행은 함께 들를지만 답합니다. 동행하는 차에는 경유지가 반영되고 패스한 차는 가던 경로를 유지합니다.

제출용 APK는 심사용 Claude 연동과 Pleos 음성 입력·안내를 사용합니다. 온라인 추천·지도·경로를 체험하려면 에뮬레이터의 인터넷 연결을 확인하고, 실제로 말해서 입력할 때는 에뮬레이터에서 호스트 마이크 입력을 켭니다.

체험할 기능
기능	앱에서 해볼 일
크루 생성·참여	방장이 정한 목적지와 6자리 코드를 공유합니다. 참여 차량은 코드를 말하거나 눌러 입력합니다. 기존에 가던 곳이 있다면 그곳을 경유한 뒤 크루 목적지로 향할 수 있습니다.
크루 위치·차량 상태	홈에서 일행 차량의 위치, 차 사이의 간격과 남은 시간, 차량별 연료 상태를 확인합니다. 퀵 드랍의 **+**에서 자주 쓰는 기능을 골라 홈에 저장합니다.
경유지 추천·투표	받는 차량을 고른 뒤 휴게소·식사·카페 등을 선택합니다. “배고파” 같은 말로도 식당 제안을 열 수 있습니다. 추천 후보와 이유를 비교하고, 원하는 장소가 없으면 직접 추가한 뒤 선택한 후보만 보냅니다.
투표 응답·경로 반영	받은 차는 후보, 아무 데나 좋아, 난 패스, 먼저 갈게 중 하나를 선택합니다. 고민되면 돌려보기는 이 차량이 낼 표 한 장의 후보를 골라 줍니다. 결정된 장소는 동행 차량의 앱 내 지도에서 확인합니다.
목적지 변경	새 목적지 한 곳을 정해 찬반을 묻습니다. 한 대라도 반대하면 기존 목적지를 유지합니다. 화면에 안내된 응답 시간 1분 안에 답이 없으면 찬성으로 처리합니다.
연료 부족·주유소 동행	내 차의 연료가 부족할 때 응, 알려줘를 눌러 주유소를 제안합니다. 제안을 받은 차량은 함께 들르거나 가던 길을 계속 갈 수 있습니다. 봇 크루의 DEMO에서 연료 경고를 재현할 수 있습니다.
한마디·음성 메시지·편지함	일행에게 한마디에서 자주 쓰는 문구를 추가·수정·삭제합니다. 녹음해서 보내기로 최대 20초의 목소리를 보내면 수신 차량이 눌러 재생합니다. 드랍 편지함은 전체 / 응답 필요 / 소셜 / 지난 결정으로 나뉩니다.
노래 드랍·따라듣기	샘플 곡을 골라 다른 차에 보내고, 받은 차에서 받아서 바로 듣기를 눌러 현재 곡과 재생 목록이 바뀌는 모습을 체험합니다. 시연 범위는 곡 정보 공유와 재생 상태 표시까지입니다. 실제 음원은 재생하지 않습니다.
정차 중 게임	게임에서 1:1 오목 도전장을 보내고 상대가 수락하면 같은 판에서 대국합니다. 초성 퀴즈는 내장 문제를, 지역 퀴즈는 위치 기반 문제를 사용합니다. DEMO에서 기어를 P → D로 바꾸면 주행 중 게임 제한을 확인할 수 있습니다.
안전운전 대결·기록	홈의 운전 기록 또는 왼쪽 기록에서 내 점수, 감점 사유, 크루 순위와 지난 주행을 확인합니다. 100점에서 급가속은 2점, 급정거는 3점씩 차감합니다. DEMO에서 D로 설정해 급가속·급정거를 재현하고 P · 최종 도착 재현으로 도착 화면을 확인합니다.
안전운전 확정 순위에는 주행 시간 60초 이상, 속도 측정률 95% 이상인 기록이 반영됩니다. 동점은 공동 순위입니다. 안전점수 판정·기록 기준

테스트 환경
항목	공모전 시연·개발 기준
차량 에뮬레이터	Pleos Connect v2.1.0 (Pleos_Connect_v2.1.0), Android Automotive OS API 34
화면 규격	팀 Windows AVD 설정은 가로 2560 × 1440 px, 160 dpi. 앱 UI 설계 기준은 가로 1600 × 900 px
지도와 앱 배치	CarDrop 앱 내부의 왼쪽 약 1/3은 경로 안내 지도, 오른쪽 약 2/3는 크루·드랍 화면
빌드 환경	Android Studio, Kotlin, Jetpack Compose, Gradle Wrapper 8.13, Gradle 데몬 JDK 21(JetBrains), JVM 타깃 17
Android SDK	compileSdk 35, targetSdk 35, minSdk 28. 에뮬레이터 실행에는 Platform-Tools, 소스 빌드에는 Android SDK Platform 35가 필요합니다.
소스로 실행하기
Android Studio에서 저장소 루트(settings.gradle.kts가 있는 폴더)를 열고 Gradle 동기화를 완료합니다. 최초 빌드에는 SDK와 의존성을 내려받을 수 있는 인터넷 연결이 필요합니다.
Device Manager에서 Pleos Connect 에뮬레이터를 실행한 뒤 app → Run ▶을 누릅니다. 소스 기본 설정에서는 외부 API 키와 Firebase 설정 파일 없이 봇 크루·샘플 추천·모의 음성 입력을 체험할 수 있습니다.
테스트용 APK만 만들거나 단위 테스트를 실행하려면 저장소 루트에서 아래 명령을 사용합니다. 디버그 APK는 app/build/outputs/apk/debug/app-debug.apk에 생성됩니다.
.\gradlew.bat assembleDebug
.\gradlew.bat testDebugUnitTest
macOS·Linux에서는 각각 ./gradlew assembleDebug, ./gradlew testDebugUnitTest를 사용합니다.

실제 음성·지도·차량·AI 연동
아래 설정은 소스에서 직접 빌드할 때 적용됩니다. 저장소 루트의 local.properties에 필요한 값만 추가하고 다시 빌드합니다. 다운로드한 APK 설치에는 이 파일이 필요하지 않습니다.

연동	설정과 적용 범위
음성 인식·안내	cardrop.useRealVoice=true로 Pleos SpeechToText·TextToSpeech SDK를 사용합니다. 에뮬레이터의 호스트 마이크 입력을 켭니다. 녹음해서 보내기에서 내 목소리를 녹음할 때는 앱의 마이크 권한도 허용합니다.
차량·위치	cardrop.useRealVehicle=true로 Pleos Vehicle SDK의 연료·주행 가능 거리 등 차량 데이터를 읽습니다. 크루 위치 도식은 지원 환경에서 Pleos FusedLocation을 우선 사용하고 Android 위치 정보로 대체합니다. 왼쪽 앱 내 길안내는 Android 위치 정보를 사용합니다.
경로·지도·장소 검색	cardrop.kakaoRestKey는 카카오모빌리티 자동차 길찾기와 카카오 장소 검색에, cardrop.kakaoNativeKey는 카카오 지도 표시에 사용합니다. 키 없이 빌드하면 OSRM 경로·MapLibre 지도·앱에 등록된 장소 목록을 사용합니다. 온라인 지도와 경로 계산에는 인터넷 연결이 필요합니다.
추천·음성 제안 해석·지역 퀴즈	cardrop.claudeApiKey를 설정하면 Claude를 호출합니다. 키가 없거나 호출에 실패하면 앱의 기본 응답을 사용합니다.
운전 기록의 AI 응원	cardrop.safetyOpenaiApiKey로 운전 기록 화면의 한국어 응원 문구를 생성합니다. 키가 없거나 응답이 늦으면 기본 문구를 표시합니다. 안전 점수는 앱의 주행 판정 규칙으로 계산합니다.
두 기기로 한 크루에 참여하기
팀 Firebase Realtime Database에 연결된 app/google-services.json을 넣습니다. 팀 프로젝트를 사용할 때는 코드에서 지정한 데이터베이스 주소와 같은 인스턴스인지 확인합니다. 별도 Firebase 프로젝트로 재현할 때는 코드의 데이터베이스 주소도 해당 인스턴스로 맞춰야 합니다.
local.properties에 cardrop.useRealCrew=true를 설정하고 다시 빌드한 앱을 인터넷에 연결된 두 기기에 설치합니다.
시작 화면의 실제 크루에서 기기마다 이름을 입력합니다. 한쪽은 방 만들기, 다른 쪽은 코드로 참여를 누릅니다. 같은 6자리 코드로 연결한 뒤 출발합니다.
첫 번째 기기에서 두 번째 차량을 골라 투표를 보내고, 두 번째 기기에서 응답합니다. 두 화면의 결과와 경로를 비교합니다. 세 번째 기기를 연결하면 수신 대상으로 선택한 차량에만 제안이 표시되는지도 확인할 수 있습니다.
에뮬레이터에서 주행 재현하기
지도 위의 차량을 실제로 움직여 보려면 Python 3.9 이상과 Android SDK Platform-Tools를 준비하고 adb를 PATH에 추가합니다. 앱을 실행한 뒤 저장소 루트에서 아래 명령을 실행하면 영동고속도로 시연 경로를 따라 GPS 좌표가 입력됩니다. 종료는 Ctrl+C입니다.

python tools/drive_gps.py
정차까지 보려면 python tools/drive_gps.py --stop 여주휴게소를 사용합니다. 여러 에뮬레이터를 띄웠다면 --serial emulator-5556처럼 adb devices에 표시된 대상 기기를 지정합니다. 주행 재현 스크립트와 옵션
